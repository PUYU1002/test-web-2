# 武侠电影数据可视化前端系统

## 项目概述

基于47部经典武侠电影数据的可视化交互系统，实现门派、武功、侠义精神三个维度的数据分析和展示。

## 🎯 核心功能

### 1. 动态背景系统
- **47张电影背景图**：每部电影对应一张专属背景图片
- **智能切换**：根据用户交互和时间自动切换背景
- **平滑过渡**：背景切换采用淡入淡出效果
- **预加载优化**：提前加载所有背景图片，确保流畅体验

### 2. 三维度河流图
- **门派维度**：武当派、少林派、峨眉派等门派数据可视化
- **武功维度**：内功心法、剑法招式、轻功身法等武功数据展示
- **侠义精神维度**：侠肝义胆、除暴安良、扶危济困等精神品质分析

### 3. 交互式控制面板
- **维度切换**：点击钻石图标切换不同维度视图
- **评分模式**：国内外对比 vs 不同国家模式
- **实时更新**：所有图表联动更新

### 4. 大数据屏设计
- **武侠主题**：古典中国风设计风格
- **响应式布局**：适配不同屏幕尺寸
- **数据驱动**：基于真实电影数据

## 🚀 技术栈

- **React 18** - 前端框架
- **Styled Components** - CSS-in-JS样式方案
- **D3.js** - 数据可视化
- **ECharts** - 图表库
- **Create React App** - 项目脚手架

## 📊 数据维度

### 门派维度 (sect)
- 武当派：道家武学，内功深厚
- 少林派：佛家武学，刚猛有力  
- 峨眉派：女性武学，柔中带刚

### 武功维度 (martialArts)
- 内功心法：修炼内力的方法
- 剑法招式：剑术技巧和招式
- 轻功身法：身法和轻功技能

### 侠义精神维度 (chivalry)
- 侠肝义胆：勇敢正义的品格
- 除暴安良：维护正义的行为
- 扶危济困：帮助弱者的精神

## 🎮 使用指南

### 1. 维度切换
点击页面右上角的钻石图标（门派、武功、精神）切换不同的数据维度视图。

### 2. 评分模式
在右侧统计面板中切换"国内外对比"和"不同国家"两种评分分析模式。

### 3. 背景交互
- 背景会根据当前选中的电影自动切换
- 支持幻灯片模式，每15秒自动切换背景
- 所有背景图片都经过优化，确保加载速度

### 4. 数据探索
- 河流图显示不同维度下的数据流向
- 统计面板提供详细的数据分析
- 图例说明帮助理解数据含义
